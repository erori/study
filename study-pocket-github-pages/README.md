# Study Pocket — версия для GitHub Pages

Это полностью статичный Mini App для студентов. Сервер, Node.js, база данных и бот не нужны.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в него **все файлы из этой папки**: `index.html`, `styles.css`, `app.js`, `content.js`, `.nojekyll`.
3. Открой `Settings → Pages`.
4. В разделе `Build and deployment` выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми `Save`.
6. Через некоторое время GitHub выдаст ссылку вида `https://username.github.io/repository-name/`.

Эту HTTPS-ссылку можно использовать как URL Mini App в BotFather.

## Что работает без сервера

- предметы и учебные темы;
- пошаговые объяснения и формулы;
- примеры решений;
- тесты с проверкой;
- поиск;
- сохранённые темы;
- прогресс обучения;
- имя и первая буква аватара из Telegram WebApp;
- мобильная адаптация.

Закладки и прогресс сохраняются в `localStorage` браузера конкретного устройства. Для общей регистрации, синхронизации между устройствами и кабинета преподавателя позже понадобится backend.
