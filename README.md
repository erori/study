# Study Pocket · ДМ 19-26

Статическое учебное мини-приложение для направления «Электроснабжение». Версия 2.0. Работает на GitHub Pages и в обычном браузере; поддерживает открытие внутри Telegram. Сервер, база данных, сборка и платные API не требуются.

## Что изменилось

- 71 тема вместо 49; добавлен самостоятельный курс электротехники и электроснабжения.
- 318 разделов теории, 77 разобранных примеров, 71 самостоятельное задание с раскрываемым решением и 71 вопрос для самопроверки.
- Матрицы разбиты на отдельные уроки: запись и операции, умножение, определители, обратная матрица и ранг, системы уравнений.
- Порядок математики исправлен: функции и пределы предшествуют производным и интегралам.
- Физика, химия и начертательная геометрия дополнены объяснениями условий применения, задачами и типичными ошибками.
- Схемы и графики нарисованы в SVG; подписи и описание доступны внутри урока.
- Оглавления уроков, поиск по тексту и формулам, увеличение текста, печать, закладки, отметки о прохождении, экспорт и импорт прогресса.

## Загрузка на GitHub Pages

1. Распакуйте архив. Загрузите **содержимое** папки `study-pocket-github-pages` в корень репозитория: `index.html` должен лежать непосредственно в выбранной папке публикации.
2. При обновлении замените старые `index.html`, `styles.css`, `app.js`, `content.js` и добавьте новый `diagrams.js`. Не загружайте только ZIP: GitHub Pages его не распаковывает.
3. В репозитории откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, нужную ветку (обычно `main`) и папку **/(root)**, сохраните.
5. Дождитесь окончания публикации. Откройте адрес, который показывает GitHub Pages. Для репозитория проекта адрес обычно имеет форму `https://USERNAME.github.io/REPOSITORY/`.

Для GitHub Free используйте публичный репозиторий. Официальная инструкция: [GitHub Pages Quickstart](https://docs.github.com/en/pages/quickstart). Домен покупать не нужно. В проекте относительные пути, поэтому размещение в подпапке репозитория поддерживается.

Если Pages уже работает, достаточно заменить файлы и дождаться обновления. При старой версии в браузере перезагрузите страницу без кэша. Приложение не регистрирует Service Worker.

## Подключение к Telegram

1. Опубликуйте сайт и проверьте его HTTPS-адрес в браузере.
2. В [BotFather](https://t.me/BotFather) выберите своего бота через `/mybots`.
3. В настройках бота настройте **Menu Button**: укажите ссылку GitHub Pages и подпись, например «Учебник». Для запуска из профиля можно настроить **Main Mini App** в настройках мини-приложения.
4. Откройте бота и запустите приложение кнопкой.

Названия меню BotFather могут меняться. Официальное описание: [Telegram Mini Apps](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button). В клиентском коде токен бота не нужен. Эта поставка — веб-приложение; обработчика сообщений и рассылок бота в ней нет.

Telegram SDK загружается асинхронно. При его недоступности учебник продолжает работать как обычный сайт; функции окна Telegram тогда недоступны.

## Прогресс

Закладки и отметки сохраняются в localStorage этого браузера для этого адреса. Автоматической синхронизации между устройствами нет. Вкладка «Прогресс» позволяет скачать JSON и загрузить его на другом устройстве. Импорт объединяет известные приложению отметки, не стирая существующие. При очистке данных браузера локальный прогресс исчезает.

Идентификаторы прежних 49 тем сохранены: старые закладки и отметки используются после обновления на том же адресе. Ответ на один тест не помечает тему пройденной автоматически — студент делает это осознанно.

## Файлы и редактирование

- `index.html` — оболочка приложения и подключение Telegram SDK.
- `styles.css` — адаптивные стили и оформление печати.
- `app.js` — навигация, поиск, уроки, прогресс.
- `content.js` — тексты всех уроков и ссылки на дополнительное чтение.
- `diagrams.js` — оригинальные SVG-схемы.
- `.nojekyll` — отключение обработки Jekyll.
- `checks/validate.cjs` — локальная проверка без внешних зависимостей.

Материалы находятся в `window.STUDY_CONTENT.subjects`. У темы есть `id`, `title`, `summary`, `objectives`, `sections`, `examples`, `practice`, `mistakes`, `links`, `quiz`. В `links` используется `предмет/id-темы`; номер правильного варианта `quiz.correct` начинается с нуля. Схема у раздела указывается полем `diagram` из списка в `diagrams.js`. Не меняйте существующие `id` без необходимости: по ним хранятся отметки.

## Проверка

При установленном Node.js из папки проекта:

```sh
node checks/validate.cjs
```

Проверены формирование всех 71 урока, структура материалов, ссылки между темами, наличие схем, логика поиска, закладок, отметок и ответов на тесты, запуск при повреждённом или недоступном хранилище. Проверка использует имитацию DOM и **не заменяет проверку в браузере**. В этой среде облачный браузер запретил доступ к локальным файлам, поэтому визуальная проверка в мобильном браузере и испытание внутри Telegram не выполнены.

Перед использованием группой откройте опубликованную версию на телефоне: проверьте урок, схему, поиск, закладку и восстановление прогресса. Для локального просмотра через HTTP при наличии Python:

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` в своём браузере.
